# Microcontroller Course Design

This repository contains the front-car and rear-car STM32 project code for the microcontroller course design.

## Structure

- `front-car/`: front car project code
- `rear-car/`: rear car project code

Generated build outputs are excluded by `.gitignore`.

## 当前版本更新说明

- 当前控制版本：分支最新提交
- 本次控制逻辑对比基准：`cdfb723`

### 前车新增内容

- 增加前车累计编码器路程统计，采用左右轮编码器增量绝对值的平均值作为前进路程。
- NRF24L01 数据包由 8 字节扩展为 12 字节，新增前车航向角和累计路程字段。
- 无线数据包当前包含速度、转向量、航向角（放大 10 倍传输）、累计编码器路程、序号和校验信息。
- OLED 最后一行增加前车累计行驶距离和当前航向角显示。
- 修正右轮编码器方向，并修正陀螺仪零偏在运行过程中被重复更新的问题。

### 后车新增内容

- 跟随方式由固定时间延迟改为按路程回放：后车根据自身累计编码器路程，从接收缓存中选择前车过去对应路程点的速度、转向量和航向角。
- 增加 256 点前车轨迹环形缓存；数据包堆满后覆盖最旧数据，不再依赖数据包序号作为执行进度。
- 前后车原始编码器数分别换算为毫米后再匹配轨迹，取消固定 2 cm 回放偏移。
- 增加后车累计里程计算。当前参数按车轮半径 22.5 mm、编码器 13 PPR、减速比 20.409、TI1 编码模式计算。
- 后车路程误差通过 `REAR_PATH_SCALE_NUM` 和 `REAR_PATH_SCALE_DEN` 校准，不再通过固定速度比例补偿。
- 当前按实车测试设置 `FOLLOW_PLAYBACK_DELAY_MM = 150`：后车先行驶 150 mm，再执行前车从起点记录的对应轨迹点。
- OLED 最后一行显示后车累计行驶距离和当前航向角，原有超声波距离、无线状态及前车数据继续保留。
- 增加完整航向角 PID，包括比例、积分、微分、积分限幅、微分低通滤波、输出限幅和停车复位。
- 直行时使用后车陀螺仪航向闭环修正左右轮差速；转弯时将前车转向前馈与航向 PID 修正叠加。
- 后车启动前增加 20 cm 距离门控：检测到前车已经运动、超声波连续稳定且距离达到 20 cm 后，才从前车起始轨迹开始执行。
- 20 cm 间距修正简化为范围门控：当前不是明显转弯、距离连续两次有效且处于 10～35 cm 时启用；不再比较航向误差和编码器估算间距。
- 超声波修正只调整基础 PWM，修正量限制为正负 80 PWM 并平滑变化；弯道或测距不可信时逐渐退出修正，不参与轨迹点和转向选择。
- 删除纯超声波距离测试模式、固定路程偏移及对应的无用状态和参数。
- 轨迹匹配内部使用微米级定点路程，避免毫米取整导致多个转弯包落在同一个路程点。
- 后车在相邻前车轨迹包之间按路程线性插值速度、转向量和航向角，丢包或跨点时不再直接跳到下一个大转向值。
- 后车控制周期由 20 ms 提高到 10 ms，并在每轮主循环优先执行电机控制。
- 每轮最多连续读取 NRF24L01 的 3 个 FIFO 数据包，减少超声波和 OLED 操作期间产生的接收积压。
- 转弯期间暂停 HC-SR04 读取，无回波超时由 30 ms 缩短为 6 ms，降低阻塞造成的控制周期抖动。
- 增加 5 mm 轨迹预瞄：利用当前位置与前方轨迹点的 `yaw` 变化估算曲率，生成后车转向前馈。
- 曲率前馈当前占 10%，前车历史 `turn` 占 90%；后车历史 `yaw` 仍作为航向 PID 的闭环目标。
- 转向前馈进入弯道时每 10 ms 最多增加 25 PWM，降低差速突变。
- 当后车距离当前轨迹点目标航向不足 25 度时，转向前馈按剩余角度逐渐衰减；达到或越过目标角后立即切断前馈。
- 转向前馈增加时每 10 ms 最多增加 25 PWM，减小时可下降 80 PWM，避免到达目标后仍因缓慢退坡而继续转动。
- 当历史轨迹满足基础速度接近 0 且转向量绝对值不小于 60 时，后车进入原地直角转弯回放：直接执行前车记录的大转向 PWM，不使用普通弯道的逐点角度减速。
- 原地转弯期间关闭超声波速度修正，航向 PID 只允许辅助当前转向方向，不能反向抵消转向前馈；历史轨迹恢复直行后自动退出该状态。

### 通信兼容性

前后车必须同时烧录当前版本。旧版本使用 8 字节数据包，当前版本使用 12 字节数据包，只更新其中一辆车会导致 NRF24L01 无法正常解析数据。

### 当前限制和下一步

- 当前采用编码器路程轨迹为主、超声波可信直线校正为辅；单个超声波仍不能从物理上完全区分前车和距离相近的环境障碍物。
- 轨迹缓存为 256 点。如果前车建立 20 cm 间距耗时过长导致缓存覆盖，最早的轨迹点仍可能丢失。
- 前后车实际轮径和编码器误差需要通过实车测量继续校准 `REAR_PATH_SCALE_NUM` 和 `REAR_PATH_SCALE_DEN`。
- 地磁计未加入当前版本，航向角目前只由陀螺仪积分获得，上电时车辆方向应保持稳定并重新建立零点。
